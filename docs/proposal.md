## บทที่ 1 บทนำ

### 1.1 ความเป็นมาและความสำคัญของปัญหา

ในยุคแห่งการเปลี่ยนผ่านสู่ดิจิทัล (Digital Transformation) เทคโนโลยีสารสนเทศได้กลายเป็นปัจจัยหลักในการขับเคลื่อนภาคธุรกิจและปรับเปลี่ยนพฤติกรรมของผู้บริโภคให้มุ่งเน้นความสะดวกสบาย ความรวดเร็ว และการเข้าถึงบริการผ่านช่องทางออนไลน์ได้ทุกที่ทุกเวลา ทั้งนี้ Digital Transformation หมายถึงการนำเทคโนโลยีดิจิทัลมาปรับใช้ร่วมกับกลยุทธ์ทางธุรกิจ เพื่อวางแผน กำหนดเป้าหมาย และดำเนินงานภายในองค์กรให้มีประสิทธิภาพมากยิ่งขึ้น ซึ่งครอบคลุมทั้งกระบวนการเปลี่ยนแปลงวิธีการทำธุรกิจแบบดั้งเดิมให้สอดคล้องกับบริบทของตลาดในปัจจุบัน

อย่างไรก็ตาม จากการสำรวจพบว่าผู้ประกอบการธุรกิจร้านถ่ายเอกสารและสื่อสิ่งพิมพ์ขนาดกลางและขนาดย่อมจำนวนมากยังคงพึ่งพากระบวนการดำเนินงานแบบดั้งเดิมเป็นหลัก เช่น การจดบันทึกรายละเอียดงานด้วยลายมือ หรือการจัดเก็บข้อมูลในรูปแบบเอกสาร ซึ่งไม่สามารถตอบสนองต่อความต้องการของตลาดในปัจจุบันได้อย่างเต็มประสิทธิภาพ ข้อจำกัดของการดำเนินงานในรูปแบบเดิมดังกล่าวนำมาซึ่งปัญหาหลายประการ อาทิ การตกหล่นของคำสั่งซื้อ ความคลาดเคลื่อนในการจัดลำดับคิว และความผิดพลาดของรายละเอียดชิ้นงาน ซึ่งส่งผลกระทบโดยตรงต่อประสิทธิภาพการให้บริการ นอกจากนี้ผู้ประกอบการยังขาดการจัดการข้อมูลอย่างเป็นระบบ ทำให้ไม่สามารถตรวจสอบรายได้หรือนำข้อมูลมาวิเคราะห์เพื่อวางแผนพัฒนาธุรกิจได้อย่างแม่นยำ ในขณะที่ฝั่งผู้ใช้บริการมักประสบปัญหาความไม่สะดวกในการเดินทางมาสั่งงาน ณ สถานประกอบการ รวมถึงไม่สามารถติดตามสถานะความคืบหน้าของงานได้

ด้วยเหตุผลดังกล่าว คณะผู้จัดทำจึงมีแนวคิดในการพัฒนา **แพลตฟอร์มบริหารจัดการร้านถ่ายเอกสาร (EasyPrint – Copy Shop Management System)** เพื่อยกระดับมาตรฐานการดำเนินงานให้มีความเป็นระบบและทันสมัย โดยแพลตฟอร์มถูกออกแบบให้มีระบบบริหารจัดการที่ยืดหยุ่น รองรับการปรับแต่งเงื่อนไขบริการ การคำนวณราคาอัตโนมัติ และการแจ้งเตือนสถานะงาน การพัฒนานวัตกรรมนี้ไม่เพียงแต่จะช่วยลดขั้นตอนที่ซับซ้อนและลดความผิดพลาดในการทำงาน แต่ยังเป็นการสร้างช่องทางเชื่อมโยงระหว่างร้านค้าและลูกค้าให้มีประสิทธิภาพสูงสุด เพื่อเพิ่มขีดความสามารถในการแข่งขันและสนับสนุนการเติบโตของธุรกิจสื่อสิ่งพิมพ์อย่างยั่งยืนในระยะยาว

### 1.2 วัตถุประสงค์

1. เพื่อพัฒนาแพลตฟอร์มบริหารจัดการร้านถ่ายเอกสาร (EasyPrint – Copy Shop Management System)
2. เพื่อเพิ่มประสิทธิภาพในการบริหารจัดการร้านถ่ายเอกสาร ด้วยระบบจัดลำดับคิวและบันทึกข้อมูลอัตโนมัติ
3. เพื่อพัฒนาระบบติดตามสถานะงานของร้านถ่ายเอกสาร

### 1.3 ขอบเขตการศึกษา

#### 1.3.1 ร้านถ่ายเอกสาร (Shop Owners)

**การสมัครสมาชิกและเข้าสู่ระบบ**
- ลงทะเบียนบัญชีผู้ใช้งานใหม่
- การเข้าสู่ระบบ

**การจัดการข้อมูลร้าน**
- ตั้งค่ารายละเอียดบริการของร้าน เช่น ชื่อร้าน, เบอร์โทรศัพท์, พิกัดตำแหน่งร้าน
- กำหนดวัน–เวลาทำการของร้าน

**การกำหนดประเภทบริการและอัตราค่าบริการ**
- กำหนดประเภทงาน เช่น ถ่ายเอกสาร พิมพ์สี โปสเตอร์
- กำหนดอัตราค่าบริการ เช่น ตามจำนวนหน้า ขนาดกระดาษ รูปแบบสี
- ตั้งค่าค่าบริการเพิ่มเติม เช่น เข้าเล่ม เคลือบใส

**การจัดการคำสั่งซื้อ**
- ตรวจสอบคำสั่งซื้อใหม่ที่เข้าสู่ระบบ
- ตรวจสอบรายละเอียดเงื่อนไขคำสั่งซื้อ
- ระบบอนุมัติหรือปฏิเสธคำสั่งซื้อ
- ระบบยกเลิกคำสั่งซื้อในกรณีที่เกิดข้อผิดพลาดในการดำเนินงาน
- แสดงรายการคำสั่งซื้อทั้งหมด

**การควบคุมและติดตามสถานะงาน**
- อัปเดตสถานะการดำเนินงาน เช่น ตรวจสอบการชำระเงิน กำลังดำเนินการ เสร็จสิ้น หรือยกเลิก
- ตรวจสอบลำดับคิวงานทั้งหมด

**การรายงานและวิเคราะห์ข้อมูล (Dashboard)**
- ดูสรุปรายได้รายวัน รายสัปดาห์ และรายเดือน
- สรุปสถิติบริการที่มียอดคำสั่งซื้อสูงที่สุด

#### 1.3.2 ผู้ใช้บริการ (Customers)

**การสมัครสมาชิกและเข้าสู่ระบบ**
- ลงทะเบียนบัญชีผู้ใช้งานใหม่
- การเข้าสู่ระบบและจัดการข้อมูลโปรไฟล์ส่วนตัว

**การสั่งพิมพ์งานออนไลน์**
- อัปโหลดไฟล์งาน
- เลือกประเภทบริการและระบุรายละเอียดงาน
- ตรวจสอบสรุปรายการและยืนยันคำสั่งซื้อ

**คำนวณราคาอัตโนมัติ**
- คำนวณราคาตามเงื่อนไขที่ร้านกำหนด
- แสดงสรุปรายละเอียดค่าบริการทั้งหมดก่อนการชำระเงิน

**การติดตามสถานะงาน**
- ตรวจสอบสถานะงานผ่าน Website
- ดูประวัติการสั่งงานย้อนหลัง

#### 1.3.3 ผู้ดูแลระบบ (Admin)

**การจัดการบัญชีผู้ใช้งาน**
- ตรวจสอบและอนุมัติการสมัครใช้งานของร้านค้า
- แก้ไข ระงับ หรือยกเลิกบัญชีร้านค้า
- ตรวจสอบข้อมูลร้านที่ลงทะเบียนในระบบ

**การควบคุมและดูแลระบบแพลตฟอร์ม**
- ตรวจสอบความถูกต้องและความปลอดภัยของข้อมูล

### 1.4.1 Tech Stack (ฉบับปรับปรุงล่าสุด)

> หมายเหตุ: รายการนี้เป็นสแตกเทคโนโลยีที่ใช้จริงในการพัฒนาโครงงาน ปรับปรุงล่าสุด — Frontend เปลี่ยนมาใช้ Next.js (App Router) ซึ่งมีระบบ routing ในตัว ไม่ต้องติดตั้ง React Router แยก ให้ AI และทีมพัฒนายึดตามส่วนนี้เป็นหลัก

**Frontend**

| เทคโนโลยี | คำอธิบาย |
|---|---|
| Next.js (App Router) | เฟรมเวิร์ก React ที่มีระบบ routing ในตัวผ่านโครงสร้างโฟลเดอร์ `app/` รองรับ Server Components ทำให้บางหน้าโหลดเร็วขึ้น และเชื่อมต่อกับ Vercel (ผู้พัฒนา Next.js) ได้ลื่นไหลที่สุด |
| TypeScript | เพิ่มความปลอดภัยในการเขียนโค้ดด้วยระบบตรวจสอบชนิดข้อมูล (Type Safety) |
| Tailwind CSS | Framework สำหรับออกแบบและจัดการหน้าตาเว็บไซต์ |
| shadcn/ui | ชุด UI Components สำเร็จรูป เช่น Table, Dialog, Form, Card และ Dashboard |
| Axios | ใช้ส่งและรับข้อมูลระหว่าง Frontend และ Backend ผ่าน REST API |

**Backend**

| เทคโนโลยี | คำอธิบาย |
|---|---|
| Bun | JavaScript Runtime สำหรับรัน Backend ที่มีประสิทธิภาพสูง |
| ElysiaJS | Backend Framework สำหรับพัฒนา REST API |
| Drizzle ORM | เครื่องมือจัดการฐานข้อมูลด้วย TypeScript แทนการเขียน SQL โดยตรง |
| Zod | ใช้ตรวจสอบและ Validate ข้อมูลก่อนประมวลผล |
| JWT (JSON Web Token) | ใช้สำหรับระบบยืนยันตัวตน (Authentication) และการเข้าสู่ระบบ |
| Argon2 | อัลกอริทึมสำหรับเข้ารหัสรหัสผ่านก่อนบันทึกลงฐานข้อมูล |

**Database**

| เทคโนโลยี | คำอธิบาย |
|---|---|
| Supabase PostgreSQL | ฐานข้อมูล PostgreSQL บน Supabase สำหรับจัดเก็บข้อมูลของระบบ เช่น ร้านค้า ผู้ใช้งาน คำสั่งซื้อ และรายงาน |

**Storage**

| เทคโนโลยี | คำอธิบาย |
|---|---|

**Deployment**

### 1.5 ประโยชน์ที่คาดว่าจะได้รับ

1. ส่งเสริมให้ร้านถ่ายเอกสารมีระบบบริหารจัดการคำสั่งซื้อและข้อมูลลูกค้า ช่วยลดความผิดพลาด ความซ้ำซ้อน และการตกหล่นของงาน
2. ลดปัญหาความคลาดเคลื่อนด้านการสื่อสารระหว่างร้านค้าและลูกค้า เนื่องจากข้อมูลคำสั่งซื้อ รายละเอียดงาน และเงื่อนไขการให้บริการถูกจัดเก็บและแสดงผลอย่างเป็นระบบ
3. สนับสนุนการนำข้อมูลมาใช้วิเคราะห์และวางแผนพัฒนาธุรกิจ โดยระบบสามารถแสดงสรุปรายได้และสถิติการใช้บริการ ช่วยให้เจ้าของร้านตัดสินใจเชิงบริหารได้อย่างเป็นระบบมากยิ่งขึ้น
4. อำนวยความสะดวกแก่ผู้ใช้บริการในการสั่งงาน อัปโหลดไฟล์ ตรวจสอบรายละเอียด และประเมินราคาค่าบริการล่วงหน้า ตลอดจนติดตามสถานะงานได้ด้วยตนเองผ่านระบบออนไลน์ ลดความจำเป็นในการเดินทางมายังหน้าร้าน
5. ยกระดับภาพลักษณ์และความน่าเชื่อถือของร้านถ่ายเอกสารให้มีความทันสมัย สอดคล้องกับบริบทของการเปลี่ยนผ่านสู่ดิจิทัล และเพิ่มขีดความสามารถในการแข่งขันในระยะยาว
6. เสริมสร้างองค์ความรู้และประสบการณ์ด้านการพัฒนาระบบซอฟต์แวร์แก่คณะผู้จัดทำโครงงาน
7. พัฒนาความรู้ด้านการบริหารธุรกิจและการวางกลยุทธ์เชิงดิจิทัล

## บทที่ 2 ทฤษฎีและงานวิจัยที่เกี่ยวข้อง

### 2.1 ทฤษฎีที่เกี่ยวข้อง

**2.1.1 การปฏิรูปสู่ดิจิทัล (Digital Transformation)**

การปฏิรูปสู่ดิจิทัลหมายถึงการนำเทคโนโลยีดิจิทัลมาปรับใช้ร่วมกับกลยุทธ์ทางธุรกิจ เพื่อวางแผน กำหนดเป้าหมาย และดำเนินการทางธุรกิจ รวมถึงการทำงานภายในองค์กร กล่าวโดยสรุปคือการนำเทคโนโลยีดิจิทัลมาเปลี่ยนแปลงวิธีการดำเนินธุรกิจให้มีประสิทธิภาพมากยิ่งขึ้น (rocket.in.th, 2567) แนวคิดนี้ถูกนำมาประยุกต์ใช้อย่างแพร่หลายในธุรกิจขนาดกลางและขนาดย่อม (SME) เพื่อยกระดับกระบวนการทำงานจากรูปแบบเอกสารและการบันทึกด้วยมือ ไปสู่ระบบดิจิทัลที่สามารถประมวลผล จัดเก็บ และวิเคราะห์ข้อมูลได้อย่างรวดเร็วและแม่นยำ ซึ่งสอดคล้องกับแนวคิดของการพัฒนาแพลตฟอร์ม EasyPrint ที่มุ่งเปลี่ยนกระบวนการดำเนินงานของร้านถ่ายเอกสารจากรูปแบบดั้งเดิมสู่ระบบออนไลน์แบบครบวงจร

**2.1.2 พาณิชย์อิเล็กทรอนิกส์ (Electronic Commerce: E-Commerce)**

พาณิชย์อิเล็กทรอนิกส์หมายถึง การทำธุรกรรมผ่านสื่ออิเล็กทรอนิกส์ในทุกช่องทาง ได้แก่ อินเทอร์เน็ตและระบบเครือข่ายคอมพิวเตอร์ ครอบคลุมกระบวนการซื้อขายสินค้าและบริการ การจัดส่ง ตลอดจนการแลกเปลี่ยนสารสนเทศระหว่างผู้ซื้อและผู้ขายโดยไม่จำเป็นต้องพบหน้ากันโดยตรง หลักการดังกล่าวถูกนำมาประยุกต์ใช้เป็นแนวทางในการออกแบบระบบสั่งพิมพ์งานออนไลน์ของแพลตฟอร์ม EasyPrint ซึ่งประกอบด้วยกระบวนการเลือกบริการ การคำนวณราคา การชำระเงิน และการติดตามสถานะคำสั่งซื้อ ในลักษณะเดียวกับระบบพาณิชย์อิเล็กทรอนิกส์ทั่วไป

### 2.2 งานวิจัยที่เกี่ยวข้อง

**2.2.1 ระบบสั่งพิมพ์งานออนไลน์บนพื้นฐานคลาวด์ (Cloud-based Printing Order Management System)**

Dhatrak และคณะ (2021) พัฒนาระบบ "Print on Air" ซึ่งเป็นระบบบริหารจัดการคำสั่งพิมพ์งานออนไลน์บนพื้นฐานคลาวด์ มีที่มาจากสถานการณ์การแพร่ระบาดของโควิด-19 ที่ทำให้ร้านถ่ายเอกสารแบบออฟไลน์มีจำนวนลูกค้าเข้าใช้บริการหน้าร้านลดลงอย่างมาก งานวิจัยออกแบบระบบที่ให้ผู้ใช้บริการอัปโหลดไฟล์งาน เลือกร้านค้าที่อยู่ใกล้เคียง คำนวณค่าบริการและระยะเวลาดำเนินงานล่วงหน้า ตลอดจนชำระเงินผ่านช่องทางอิเล็กทรอนิกส์ได้หลายรูปแบบ รองรับการจัดเก็บประวัติคำสั่งซื้อ การจัดการใบแจ้งหนี้ และการแจ้งเตือนอัตโนมัติเมื่องานเสร็จสิ้น สอดคล้องโดยตรงกับฟังก์ชันการอัปโหลดไฟล์ การคำนวณราคาอัตโนมัติ และการติดตามสถานะงานของแพลตฟอร์ม EasyPrint

**2.2.2 ระบบบริการพิมพ์งานภายในสถานศึกษา (Campus Printing Service System)**

Lu, Mao, Wang และ Tan (2019) ศึกษาปัญหาการใช้บริการพิมพ์เอกสารของนิสิตนักศึกษา พบว่าบริการพิมพ์งานแบบดั้งเดิมมีต้นทุนด้านเวลาสูงและประสิทธิภาพต่ำ เนื่องจากเครื่องพิมพ์ไม่สามารถบันทึกหรือวิเคราะห์ข้อมูลการใช้งานได้ งานวิจัยนำเสนอการออกแบบและพัฒนาระบบบริการพิมพ์งานผ่านเว็บ ทั้งด้านเฟรมเวิร์กที่ใช้พัฒนา การออกแบบฐานข้อมูล และการออกแบบโมดูลฟังก์ชันการทำงาน แนวทางนี้ถูกนำมาใช้เป็นต้นแบบในการออกแบบโครงสร้างฐานข้อมูลและโมดูลการทำงานของแพลตฟอร์ม EasyPrint ทั้งในส่วนของร้านค้า ผู้ใช้บริการ และผู้ดูแลระบบ

**2.2.3 ระบบสั่งพิมพ์และถ่ายเอกสารผ่านเว็บไซต์ (Web-based Print and Copy Ordering System)**

งานวิจัยที่ตีพิมพ์ใน Aptisi Transactions on Technopreneurship (2019) ศึกษาปัญหาของศูนย์บริการพิมพ์และถ่ายเอกสารภายในสถาบันการศึกษาแห่งหนึ่ง ซึ่งแต่เดิมนักศึกษาต้องเดินทางมาต่อคิวที่หน้าร้านเพื่อสั่งพิมพ์หรือถ่ายเอกสารด้วยตนเอง ก่อให้เกิดความล่าช้าและความไม่สะดวก คณะผู้วิจัยพัฒนาระบบสั่งซื้อบริการผ่านเว็บไซต์ให้นักศึกษาสั่งงานได้จากระยะไกลโดยไม่ต้องเดินทางมาต่อคิว ผลการศึกษาพบว่าช่วยลดขั้นตอนการสั่งซื้อและเพิ่มความสะดวกให้แก่ผู้ใช้บริการได้อย่างมีนัยสำคัญ เป็นแนวทางสำคัญในการออกแบบระบบจัดคิวและระบบสั่งพิมพ์งานออนไลน์ของแพลตฟอร์ม EasyPrint

**2.2.4 แนวโน้มการปฏิรูปสู่ดิจิทัลของธุรกิจขนาดกลางและขนาดย่อม**

ข้อมูลจากภาคธุรกิจชี้ให้เห็นว่าองค์กรและธุรกิจในประเทศไทยจำนวนมากกำลังอยู่ในกระบวนการปรับตัวสู่ดิจิทัล โดยเฉพาะธุรกิจบริการขนาดเล็กที่แต่เดิมพึ่งพาการทำงานแบบดั้งเดิม การนำเทคโนโลยีดิจิทัลเข้ามาช่วยจัดการข้อมูลและกระบวนการทำงานสามารถช่วยลดต้นทุน เพิ่มประสิทธิภาพการดำเนินงาน และสร้างความได้เปรียบในการแข่งขันได้ (SCB TechX, 2567)

**สรุป:** แนวคิดของระบบสั่งพิมพ์งานและระบบบริหารจัดการร้านถ่ายเอกสารออนไลน์ได้รับการศึกษาและพัฒนาอย่างต่อเนื่องในหลายบริบท ทั้งเชิงพาณิชย์ สถานศึกษา และศูนย์บริการภายในมหาวิทยาลัย ล้วนมุ่งแก้ปัญหาความล่าช้าในการสั่งงาน การจัดคิว และการขาดระบบติดตามสถานะงาน คณะผู้จัดทำจึงนำแนวคิดหลัก ได้แก่ การอัปโหลดไฟล์งานออนไลน์ การคำนวณราคาอัตโนมัติ การออกแบบฐานข้อมูลและโมดูลการทำงานที่รองรับหลายร้านค้า และการจัดการคิวและสถานะงาน มาประยุกต์ใช้ร่วมกับหลักการปฏิรูปสู่ดิจิทัลและพาณิชย์อิเล็กทรอนิกส์

## บทที่ 3 วิธีการดำเนินงาน

### 3.1 การศึกษาและวิเคราะห์ปัญหา
ศึกษาสภาพปัญหาของธุรกิจร้านถ่ายเอกสารจากการสำรวจและรวบรวมข้อมูล เพื่อวิเคราะห์ความต้องการของกลุ่มเป้าหมายทั้ง 3 กลุ่ม ได้แก่ ร้านถ่ายเอกสาร ผู้ใช้บริการ และผู้ดูแลระบบ แล้วนำผลการวิเคราะห์มากำหนดขอบเขตและวัตถุประสงค์ของโครงงาน

### 3.2 การออกแบบระบบ
ออกแบบสถาปัตยกรรมระบบและฐานข้อมูลด้วยเครื่องมือ Draw.io เพื่อจัดทำแผนภาพ Use Case Diagram และ Entity Relationship Diagram (ERD) พร้อมทั้งออกแบบส่วนติดต่อผู้ใช้งาน (UI/UX) ด้วยโปรแกรม Figma เพื่อกำหนดโครงสร้างหน้าจอและรูปแบบการใช้งานของทั้งสามกลุ่มผู้ใช้

### 3.3 การวางแผนงาน
จัดทำ Product Backlog และแบ่งงานออกเป็น Sprint ย่อยด้วยเครื่องมือ Jira โดยกำหนดลำดับความสำคัญของฟีเจอร์ต่าง ๆ ตามความจำเป็นในการใช้งานจริง เพื่อให้สามารถพัฒนาและส่งมอบผลลัพธ์ได้อย่างต่อเนื่องเป็นรอบ

### 3.4 การพัฒนาระบบ
พัฒนาส่วนหน้า (Frontend) และส่วนหลัง (Backend) ของระบบด้วยเฟรมเวิร์ก Next.js ร่วมกับภาษา TypeScript และจัดรูปแบบส่วนติดต่อผู้ใช้งานด้วย Tailwind CSS โดยใช้ Node.js เป็นสภาพแวดล้อมประมวลผลฝั่งเซิร์ฟเวอร์ พัฒนาระบบจัดการฐานข้อมูลด้วย DBeaver และพัฒนาโค้ดผ่านโปรแกรม Antigravity และควบคุมเวอร์ชันของซอร์สโค้ดด้วย GitLab และ GitHub

### 3.5 การทดสอบระบบ
ทดสอบการเชื่อมต่อและความถูกต้องของ API ด้วยเครื่องมือ Postman ทดสอบการทำงานของระบบในภาพรวม (Functional Testing) ตามขอบเขตที่กำหนดไว้ในแต่ละกลุ่มผู้ใช้งาน และตรวจสอบแก้ไขข้อผิดพลาดที่พบก่อนนำระบบไปใช้งานจริง

### 3.6 การนำระบบไปใช้งานและประเมินผล
นำแพลตฟอร์มไปทดลองใช้งานกับกลุ่มเป้าหมาย เก็บรวบรวมข้อเสนอแนะและปัญหาที่พบระหว่างการใช้งานจริง เพื่อนำมาปรับปรุงระบบให้มีประสิทธิภาพยิ่งขึ้น พร้อมทั้งจัดทำรายงานสรุปผลการดำเนินโครงงานฉบับสมบูรณ์
